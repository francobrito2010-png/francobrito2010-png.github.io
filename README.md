# Portafolio — Franco®

Mi portafolio personal: catálogo de trabajos (webs, apps, diseño, imágenes, animación, 3D).
Sitio estático de un solo archivo, sin dependencias.

## Cómo agregar un trabajo
Abre `index.html` y busca los bloques marcados con `⚙️` arriba del `<script>`:
- **MARCA** — tu nombre, foto, frase y redes.
- **CATEGORIAS** — las pestañas de filtro.
- **PROYECTOS** — copia un bloque `{ ... }` para añadir un trabajo. Las imágenes van en la carpeta `img/`.
